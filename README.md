# Git_Repo_DevOps_Learning
Git Repo for DevOps Learning
1. Created a repo in github named "Git_Repo_DevOps_Learning".
2. Created a folder in local machine name "Git_test_DevOps"
3. Repo creation
git clone
4. performed following commands in local machine folder 
a. git status
b. git add *
c. git status
d. git commit -m "updated README.md"
e. git push

5. created branch
git checkout -b "Ranjeet_Develop"
6. performed following commands in local machine folder 
a. git status
b. git add *
c. git status
d. git commit -m "updated README.md in Ranjeet_Develop branch"

6. git push -u origin Ranjeet_Develop


OR 
Repo creation
1. git init 
2. git remote add origin <URL>
3. git pull origin main

created branch
git branch "Ranjeet_Develop"
git checkout "Ranjeet_Develop" or git switch "Ranjeet_Develop"
